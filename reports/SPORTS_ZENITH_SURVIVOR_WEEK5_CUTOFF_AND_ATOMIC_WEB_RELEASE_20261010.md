## New original-source deadline adjudication
- `commercial_web/survivor_pick_window.js` is a pure read-only **server-side** original-source authority that parses the actual season's `nfl_live/derived/NFLVERSE_2026_SCHEDULE.csv`, determines the verified **Saturday 6:00 PM America/New_York** cutoff of the requested season week from its Sunday fixtures, and honors the earlier kickoff-day two-hours-before-first-game exception.
- It requires 12–16 unique fixture IDs/teams per verified NFL regular-season week, original date, kickoff, ESPN event IDs, exact source game identities/abbreviations and provider ESPN scoreboard matching for any team allowed to be edited. It checks the scoreboard's observed age and labels a stale or mismatched source **not verifiable**, rather than assuming a game or team is valid. Source calendar SHA256 is attached to the private authorized receipt. Verified per-team cutoff UTC values are included so browser controls close at the exact moment even between state refreshes. Time-zone offsets are resolved using America/New_York (including November EST, not a hard-coded October EDT).
- A status is `WINDOW_OPEN` only if the entire source passes integrity and at least one real current-week verified unused team is actually still inside both relevant cutoff and unstarted-game time. At exact Saturday 6PM, `WINDOW_CLOSED` with reason `SATURDAY_POOL_DEADLINE_PASSED` always returns `editable_teams:[]`. False ALIVE or a signed-in session does not re-open the edit window. If the source is incomplete or contradictory, saving remains locked pending source review.
- New private `pick_window` in **existing authenticated** `/api/survivor/state` follows the user's already verified linked entry, original rule status, exact owner-specific used/current picks and current scoreboard. An unauthenticated visitor still receives HTTP 401 and never sees the private receipt.
