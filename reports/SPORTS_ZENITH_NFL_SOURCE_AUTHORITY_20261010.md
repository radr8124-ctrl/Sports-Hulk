## Implementation and source proof
- New pure/read-only `commercial_web/nfl_source_authority.js` recomputes freshness from the actual source provider **updated_at + collector collected_at** (6h maximum inside 24h of NFL kickoff, 24h beyond), refuses future/non-timezone timestamps, validates official ESPN game/event and kickoff uniqueness, rejects ambiguous duplicate original game rows and source identity mismatches. A fake fresh `LIVE` status never overrides the actual capture age. Even if a fresh primary quote appears later, it will be labeled `PRIMARY_TIME_FRESH_EXECUTION_UNVERIFIED` rather than automatically executable or profitable.
- It separately SHA-verifies the exact historical SportWizzard archive bytes, archive capture time encoded in its original filename, signed original research-only classification, same book two-sided lines, valid moneyline prices and hold, official ESPN numeric event, home/away abbreviations, source-time, quote and kickoff. Invalid bytes, source time, future game, unverified official mapping or a duplicate event means **no current research-quote count**. Never turns a SportWizzard research pair into a Propline primary current book replacement or authorizes a bet.
- New aggregate-only public `GET /api/nfl/book-source-health` in the existing commercial Node server. No user/Survivor entry identifiers, raw quote prices, user records or vendor credentials. No-store response is rebuilt against current original source files each request; when ESPN official scoreboard freshness/identity fails, it returns a source unavailable status rather than zero-game coverage. It never writes original sources, model coefficients, predictions, bankroll, saved picks or official pool imports.
- Shared `src/NflBookSourceHealth.jsx` compact retro-modern source display is shown on the existing `#survivor` sportsbook review and `#best-bets` odds board (only when NFL or All sports). It shows original-primary SOURCE-FRESH count vs future official fixtures, separate recent archived two-sided research count, and an obvious **NOT LIVE** warning. Expand **Why isn't this a live offer?** for original provider update time, verified archive SHA, quota-last-observed status, and why neither source proves independent advantage. Full original odds and Survivor pages/filters remain intact; the widget is read-only.
