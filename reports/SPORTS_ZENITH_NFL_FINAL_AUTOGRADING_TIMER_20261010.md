## New protected read-only score observer
- `scripts/zenith_nfl_final_observer.py`: two explicit modes. `--verify-only` does NO networking, no ledger write, no receipt update. `--run` snapshots immutable original forecast-prefix SHA, original Survivor forward-ledger first-row SHA, and an in-memory SHA of ALL existing private Survivor entries' selection/used-team/official submission/status semantics (no member names in receipts). Aborts if original frozen records do not match. Invokes ONLY existing independent Final source collector followed by pre-existing scorer, each with firm timeouts, then verifies source hashes and private entry semantics UNCHANGED; uses the strict aggregate-only `commercial_web/nfl_model_validation.js` readback before and after to prevent false Brier/log-loss performance claims. Refuses mismatched paired Final scoring counts. Writes an atomic SHA-readback-verified, private 0600 aggregate receipt `intelligence_warehouse/nfl_advanced_pregame/NFL_FORWARD_OFFICIAL_OBSERVER_CURRENT.json` after complete success. Never submits Survivor choices, modifies model coefficients, changes frozen observations, or calls sportsbook APIs.
- `scripts/zenith_nfl_final_proof_readback.mjs`: loads only original aggregated NFL prediction, verified Final, scored-game sources, scorer summary and public 2025 historical diagnostics; returns a single data-minimal JSON line or fails if source integrity or no-edge policy conflicts. No user-specific records.
- Versioned user-systemd templates in `deploy/systemd/user/sports-zenith-nfl-final-observer.{service,timer}`. Installed byte-for-byte with SHA readback to `~/.config/systemd/user/`. The **timer was enabled and verified ACTIVE**. Calendar `*-*-* *:37:00 UTC`, once per hour with 90 seconds accuracy, Persistent=true. One-shot service has an exclusive flock guard, 85-second process timeout, NoNewPrivileges and conservative umask. Existing source modules at most check two NFL weeks per iteration and skip ESPN network entirely unless after kickoff and the original NFLverse source has both scores; free public-only source.
