# Sports HULK Starter

First build:
- NFL game slate + odds/market stats
- College Football game slate + odds/market stats (NO college player props)
- NFL Survivor Top 5 market baseline
- Local cache
- SportsGameOdds usage check

## Mac setup
1. Unzip in Downloads.
2. Double-click `INSTALL_SPORTS_HULK.command`.
3. Put your private SportsGameOdds key in `.env`.
4. Double-click `RUN_SPORTS_HULK.command`.

This first Survivor card is intentionally market-only. It is the foundation, not the final model.
